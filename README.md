# RoughBog

RoughBog is a high-performance, fault-tolerant data aggregator that enables real-time processing and auto-scaling for efficient data management.

With RoughBog, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughBog.git`
2. `cd RoughBog`
3. Install in editable mode: `pip install -e .`

## Configuration

RoughBog is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
